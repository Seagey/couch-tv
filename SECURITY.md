# Security policy

## Supported versions

Only the latest release and the current main branch get security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately here: https://github.com/Seagey/couch-tv/security/advisories/new

Include what you found, the steps to reproduce it, and which version you tested.

What to expect:

- A first reply within a few days.
- A fix first, then a public note once it is safe.
- A credit in the release notes if you want one.
