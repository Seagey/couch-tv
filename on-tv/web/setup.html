ADB on the TV

Keys, typing, power off and "what's playing" need the TV's own debugging switched on. Opening apps and volume work without it.

Wireless debugging pairing (Android 11 and newer, best for Google TV)

  1. On the TV: Settings, System, About, press Build seven times to unlock Developer options.
  2. Settings, System, Developer options, Wireless debugging, switch it on, and on "Allow wireless debugging on this network?" tick Always allow on this network and choose Allow. The TV must be on Wi-Fi.
  3. Careful: Revoke USB debugging authorizations sits right next to Wireless debugging in that list. Never press OK on it.
  4. In Wireless debugging choose Pair device with pairing code. Leave that screen open on the TV.
  5. Type the 6 digit code here. The port is optional (it is found on its own).

Network debugging on port 5555 (older Android TV, Fire TV, Shield)

Switch on Developer options and Network (or USB) debugging, press Connect, then on the TV tick Always allow and press Allow. Some newer Google TVs never show that question: use pairing above instead.

Kids mode (optional, off unless you say yes)

Any young kids who should only see shows you've picked? I can set up a kids mode with a PIN. Their TV home then shows only the shows you add, and leaving it needs the PIN. Skip this and nothing changes.

Ask (optional, off by default)

On-TV mode has no Claude unless you add your own Anthropic API key. Each ask uses Claude Haiku 5.5 and costs about a fifth of a US cent. Use a key made only for this TV, with a monthly spend limit set in the Anthropic Console: the key is stored on the TV, and anyone with ADB access to the TV could read it.
